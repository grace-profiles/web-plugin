You can always get information about the provided command and available features executing
`grace profile-info web-plugin`

You will see an output similar to:

[source, bash]
----

Description: Profile for Plugins designed for Web applications

----------------------------------------------------------------------------------------------------

----------------------------------------------------------------------------------------------------
asset-pipeline                                       Adds Asset Pipeline to a Grace project

async                                                Adds support for the Grace Async
